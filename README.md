# Snake Game in C++

## Instructions for Team Members

1. Open the file `snake.cpp` in this repository.
2. Click on the file and copy all the code.
3. Open Visual Studio Code or any C++ text editor.
4. Create a new file named:

snake.cpp

5. Paste the copied code into the file.
6. Save the file.

## Compile the Program

Open the terminal and run:

g++ snake.cpp -o snake

## Run the Program

Run:

.\snake

## Controls

W = Up

A = Left

S = Down

D = Right

P = Pause / Resume

R = Restart

ESC = Exit

## Features

* Snake movement
* Fruit collection
* Score system
* Snake growth
* Pause and resume
* Restart option
* Game Over screen
